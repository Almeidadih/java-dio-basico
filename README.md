# java-dio-basico - Sistema de Cadastro de Produtos (Java Desktop)

# Funcionalidades PrincipaisTela Inicial de Boas-Vindas: Uma interface de entrada colorida (azul, verde e amarelo claros) com uma mensagem de boas-vindas e um botão para navegar até a tela de cadastro de produtos.
# Tela de Cadastro de Produtos: Uma interface dedicada ao cadastro de novos produtos, apresentada em um agradável tom de verde claro. 
# Permite inserir nome, descrição, preço e quantidade.Validação Básica: Implementa validação para garantir que os campos de preço e quantidade sejam numéricos válidos.
# Exibição de Produtos: Os produtos cadastrados são exibidos em uma área de texto na própria tela de cadastro (dados armazenados apenas em memória durante a execução).
# Navegação Bidirecional: Permite transitar entre a tela inicial e a tela de cadastro de produtos.Design com Cores Claras: Toda a interface é projetada com uma paleta de cores suaves e claras para garantir 
# legibilidade e conforto visual, evitando distorções. 
# Tecnologias UtilizadasJava Development Kit (JDK) 21+: Linguagem e ambiente de execução.Swing: Toolkit de interface gráfica para Java.Maven: Ferramenta de automação de construção e gerenciamento de 
# dependências.IntelliJ IDEA: Ambiente de Desenvolvimento Integrado (IDE) utilizado no desenvolvimento.
# Git: Sistema de controle de versão para gerenciar o código-fonte.GitHub: Plataforma de hospedagem de repositórios Git.
